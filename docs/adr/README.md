# Architecture Decision Records

Ek ADR tab likho jab koi decision **badalna mehnga** ho.

Template:

```
# ADR-00X: <Title>

**Date:** YYYY-MM-DD
**Status:** Proposed | Accepted | Superseded by ADR-00Y

## Context
Problem kya hai, constraints kya hain.

## Options Considered
1. Option A — pros / cons
2. Option B — pros / cons

## Decision
Kya choose kiya aur kyun.

## Consequences
Ab kya easy ho gaya, kya mushkil ho gaya, kya future me revisit karna padega.
```
